# Third-party assets

Almanac bundles these so it works offline on the home screen, with no calls to outside font or icon services.

| What | Where it's used | Licence |
| --- | --- | --- |
| [Figtree](https://github.com/erikdkennedy/figtree) by Erik Kennedy, copied into `public/fonts/` | Digits 0–9 ("Almanac Digits") | SIL Open Font License 1.1 (see `public/fonts/OFL-figtree.txt`) |
| [Atkinson Hyperlegible Next](https://www.brailleinstitute.org/freefont/) by the Braille Institute, copied into `public/fonts/` | Printed text | SIL Open Font License 1.1 (see `public/fonts/OFL-atkinson-hyperlegible-next.txt`) |
| [Shantell Sans](https://shantellsans.com) by Shantell Martin, copied into `public/fonts/` | Family-written things (events, list items, meals) when handwriting is on | SIL Open Font License 1.1 (see `public/fonts/OFL-shantell-sans.txt`) |
| [Phosphor Icons](https://phosphoricons.com), via `@phosphor-icons/react` | Buttons and the left rail | MIT (see `node_modules/@phosphor-icons/react/LICENSE`) |
| [Fluent Emoji](https://github.com/microsoft/fluentui-emoji) 3D images by Microsoft, copied into `public/emoji/` | Pictures on events and routine steps | MIT (see `public/emoji/LICENSE-fluent-emoji.txt`) |
