# Third-party assets

Almanac bundles these so it works offline on the home screen, with no calls to outside font or icon services.

| What | Where it's used | Licence |
| --- | --- | --- |
| [Atkinson Hyperlegible Next](https://www.brailleinstitute.org/freefont/) by the Braille Institute, via `@fontsource-variable/atkinson-hyperlegible-next` | All text | SIL Open Font License 1.1 (see `node_modules/@fontsource-variable/atkinson-hyperlegible-next/LICENSE`) |
| [Kalam](https://fonts.google.com/specimen/Kalam) by the Indian Type Foundry, via `@fontsource/kalam` | Family-written things (to-dos, meals, notes) when handwriting is on | SIL Open Font License 1.1 (see `node_modules/@fontsource/kalam/LICENSE`) |
| [Phosphor Icons](https://phosphoricons.com), via `@phosphor-icons/react` | Buttons and the left rail | MIT (see `node_modules/@phosphor-icons/react/LICENSE`) |
| [Fluent Emoji](https://github.com/microsoft/fluentui-emoji) 3D images by Microsoft, copied into `public/emoji/` | Pictures on events and routine steps | MIT (see `public/emoji/LICENSE-fluent-emoji.txt`) |
